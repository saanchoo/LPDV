# 🎵 LPDV (La Playlist Del Vago)

Generador automático de playlists basado en tu historial de Spotify. Menos pensar, más escuchar.

## 🚀 Quick Start

1.  **Instalar dependencias:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Configurar:**
    Crea un archivo `.env` en la raíz y añade tus credenciales de Spotify (`CLIENT_ID`, `CLIENT_SECRET`, etc.).

3.  **Arrancar:**
    ```bash
    python run.py
    ```
